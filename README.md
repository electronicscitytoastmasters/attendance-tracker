# Electronics City Toastmasters — Attendance Tracker

Self-hosted attendance tracker for weekly Saturday meetings.

## Quick start

```
npm install
npm run dev          # local dev at http://localhost:5173/attendance/
npm run build        # production build
npm run deploy       # build + push to GitHub Pages
```

## Stack

- **React 18** + Vite
- **Google Sheets** (via Apps Script) as shared backend
- **GitHub Pages** for hosting (free)
- `xlsx` for Excel export, `recharts` for charts, `lucide-react` for icons
